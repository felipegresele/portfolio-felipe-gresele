# 💼 Portfólio | Felipe Gresele

Portfólio pessoal responsivo, com cenas 3D e animações, que apresenta meus projetos, experiência e contato.

## ✨ Funcionalidades

- Layout responsivo (mobile, tablet e desktop)
- Cenas 3D interativas com React Three Fiber (computador, planeta e estrelas)
- Animações de entrada com Framer Motion
- Seção de projetos com links para demo e repositório
- Linha do tempo de experiência profissional
- Seção do GitHub com dados e contribuições em tempo real
- Formulário de contato com envio de e-mail via EmailJS
- Download do currículo em PDF

## 🛠️ Tecnologias

- **React 18** + **Vite**
- **Tailwind CSS**
- **Three.js** (`@react-three/fiber` e `@react-three/drei`)
- **Framer Motion**
- **React Router**
- **EmailJS** (envio de e-mails)
- **GitHub API** (dados da seção GitHub)

## 📁 Estrutura

```bash
src/
├── api/          # Integração com a API do GitHub
├── assets/       # Imagens, ícones e logos
├── components/   # Seções do site (Hero, About, Work, Contact...)
│   └── canvas/   # Cenas 3D
├── constants/    # Projetos, tecnologias e links de navegação
├── hoc/          # Wrapper das seções
└── utils/        # Variantes de animação
public/           # Modelos 3D e currículo
```

## 🚀 Como rodar localmente

```bash
git clone https://github.com/felipegresele/portfolio-felipe-gresele.git
cd portfolio-felipe-gresele
npm install
npm run dev
```

Acesse `http://localhost:5173`.

Para gerar o build de produção: `npm run build`
